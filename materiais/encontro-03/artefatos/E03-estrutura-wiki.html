Encontro 03 · LLM Wiki e Agente de Código

A estrutura: raw/, wiki/, CLAUDE.md

Base de conhecimento própria, onde o mesmo arquivo que você lê para trabalhar é o que o agente lê para executar.

"Obsidian é a IDE; o LLM é o programador; a wiki é a base de código." — Andrej Karpathy, gist llm-wiki, 04/04/2026

A mudança de ideia: RAG × LLM Wiki

RAG — o padrão anterior

  • O trabalho acontece a cada pergunta
  • Entre as perguntas não existe nada
  • Cada resposta é remontada do zero

LLM Wiki

  • O trabalho acontece uma vez, na ingestão
  • Entre as perguntas existe uma wiki que cresce
  • Artefato permanente que se acumula

RAG é cozinhar do zero toda vez que dá fome. O LLM Wiki é ter uma despensa organizada.

Três camadas, uma pasta

raw/
Fontes originais: lâmina PDF, ata, transcrição, planilha. Nunca alterada.
edita: você
wiki/
Páginas markdown interligadas — sua base de conhecimento. Toda afirmação cita a fonte em raw/.
edita: o modelo,
sob sua revisão
CLAUDE.md
Instrução persistente: como o modelo lê raw/ e escreve wiki/. Vale em toda conversa.
edita: você

Três operações

ingest

Uma fonte de raw/ vira páginas em wiki/.

query

Perguntar à wiki — resposta com a sua base, não com o que o modelo acha.

lint

Auditar consistência: contradições, páginas órfãs, afirmações sem citação.

A seta que fecha o ciclo: toda correção que você faz na revisão volta para o CLAUDE.md. É o que faz o sistema melhorar sozinho, em vez de você repetir a mesma correção todo mês.

O que o curso adiciona ao padrão original

A regra de citação obrigatória. No gist as citações são possibilidade; aqui são condição: toda afirmação em wiki/ aponta para o arquivo de raw/ de onde veio. O motivo é regulatório — o art. 23 da Resolução CVM 19 exige guarda por 5 anos da documentação que fundamentou recomendações.
